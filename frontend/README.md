Интернет-магазин светодиодных ламп и светильников на React (Vite) с роутингом и корзиной.

Запуск

1. Установите [Node.js](https://nodejs.org/) (версия 18 или выше).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Vanusha61/m_front_l.git
   cd m_front_l
Установите зависимости:
npm install
Запустите проект:

npm run dev
Откройте в браузере http://localhost:5173
